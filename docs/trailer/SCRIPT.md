# STICKCHERS — Launch Trailer Script

**Working title:** *Six Archers. One Arena.*  
**Runtime:** 60 s master  
**Cut-downs:** 30 s (X/Reels), 15 s (store preview)  
**Format:** 1920×1080, 30 fps, H.264 + AAC  
**Rendering:** Fully 3D in Blender Eevee, rendered from the game's own 3D models  
**Tone:** Heroic, adventurous, fast, premium cinematic with playful character moments  
**Core rule:** Nobody loses. Every arrow is dodged, redirected, caught, or answered.

---

# 1. Creative Direction

The trailer should feel like a **premium cinematic trailer for a ridiculous stickman archery game**.

The characters take themselves seriously. The world feels epic. The camera is cinematic. The archery is precise. But each character has one small personality detail that makes them memorable.

The trailer's progression is:

> **Mystery → Character Reveal → Competition → Escalation → Six-Archer Showdown → Logo**

The audience should finish the trailer thinking:

> **"I want to play as that guy."**

### Core principles

- Every hero must look equally competent.
- Never show a hero being hit.
- Never show a hero falling or losing.
- Every attack should create a cooler response.
- Prioritize clean, readable action over complicated VFX.
- Use cinematic camera movement rather than excessive effects.
- Characters and environments must match the actual game.
- The trailer should clearly communicate that this is a **game**, not only an animated short.
- Use the reference trailers as a **visual grammar**, not as a shot-for-shot template.

### Visual grammar borrowed from the references

**Detail → Character reveal → Personality → Action → Escalation → Group payoff**

For Stickchers:

**Arrow → Archer → Personality → Dodge → Counter → Six-archer showdown**

# 12. Arrow System

Do **not** rely on uncontrolled physics simulation for important cinematic shots.

Use deterministic animation.

Create:

```text
shoot(from, to, duration)
```

The helper should animate:

- arrow position
- arrow orientation
- release timing
- impact timing
- optional camera attachment

For cinematic shots:

> **Animation control > physics simulation**

Every important arrow must arrive at the intended frame.

This is especially important for:

- arrow-cam
- near misses
- dodges
- catches
- redirected arrows
- final volley

# 17. Review Loop

Create:

```bash
rig/render.py --sheet
```

The contact sheet should show approximately one frame every 0.5 seconds.

Review in this order:

### Pass 1 — Pacing

Ask:

- Does every shot land on the music?
- Are any shots too long?
- Is the character reveal too slow?
- Does Act III escalate?

### Pass 2 — Story clarity

Ask:

- Do I understand there are six characters?
- Do I understand they are archers?
- Does every character feel competent?
- Does the duel sequence feel connected?

### Pass 3 — Lighting

Ask:

- Do all six arenas feel premium?
- Do characters separate from backgrounds?
- Is the fog helping rather than hiding the characters?

### Pass 4 — Animation

Ask:

- Are movements readable?
- Are dodges believable?
- Are arrow trajectories clean?
- Do hair/clothing reactions happen slightly after movement where appropriate?

### Pass 5 — Pixels

Only after the above are approved:

- materials
- reflections
- particles
- DOF
- motion blur
- small VFX
